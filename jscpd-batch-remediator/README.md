# jscpd-batch-remediator

This skill packages a deterministic `jscpd` cleanup loop for Meridian Python and backend C# code.

Use it when you want an agent to regenerate the current duplicate report through the repo-owned wrapper for the requested profile, work from a cluster-based JSONL worklist, and consolidate repeated logic even when the right fix crosses file boundaries.

Final responses must list both fixed and skipped cluster IDs. Structural extraction is expected work for this skill, not a reason to defer findings.
